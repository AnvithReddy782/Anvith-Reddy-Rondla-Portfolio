# Tech Stack

Analysis of the technology stack for the Anvith Reddy Rondla Portfolio.

## Core
- **Framework:** Next.js 16.1.6 (App Router)
- **Library:** React 19.2.4
- **Language:** TypeScript 5.9.3
- **Runtime:** Node.js

## Styling & Theme
- **CSS:** Tailwind CSS 4.2.1
- **Post-processing:** PostCSS 8.5.8, Autoprefixer 10.4.27
- **Fonts (External):**
  - **Fontshare:** Clash Display (Display), General Sans (Body)
  - **Google Fonts:** JetBrains Mono (Technical/Mono)
- **Design System:** Custom "Axiom" design system with translucent tokens, glassmorphism, and cinematic animations.

## Motion & Experience
- **Animations:** Framer Motion 12.36.0
- **Interaction Physics:** GSAP 3.14.2
- **Smooth Scrolling:** Lenis 1.3.18
- **Icons:** Lucide React 0.577.0

## Content Management
- **Format:** MDX / Markdown
- **Processing:** `next-mdx-remote` 6.0.0, `gray-matter` 4.0.3

## Development Tools
- **Linter:** ESLint 9.39.4 with `eslint-config-next`
- **Builder:** Next.js native build system
