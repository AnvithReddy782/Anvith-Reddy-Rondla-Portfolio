# Requirements: Anvith Portfolio (Spatial Blueprint)

**Defined:** 2026-03-16
**Core Value:** Prove building instinct and PM discipline through an immersive "Spatial Blueprint" narrative.

## v1 Requirements

### 1. Visual & Spatial Foundation (VIS)
- [ ] **VIS-01**: Implement a 3D Spatial Grid backdrop using React Three Fiber.
- [ ] **VIS-02**: Transition design system tokens from "Axiom" to personal "builder" identity.
- [ ] **VIS-03**: Background must respond to cursor position (depth/parallax) and scroll velocity.
- [ ] **VIS-04**: Achieve 60FPS performance on average modern hardware (M1/i7 equivalents).

### 2. Signature Interactions (INT)
- [ ] **INT-01**: Implement "Blueprint Reveal" scroll-triggered animations for core sections.
- [ ] **INT-02**: Visual effect: transition from wireframe/documentation (planning) to high-fidelity UI (shipping).
- [ ] **INT-03**: FLIP-based card expansions from product grid to full case study view.
- [ ] **INT-04**: Interactive Neural Web for skill visualization with pulse/connection effects.

### 3. Product & Evidence Showcase (PROD)
- [ ] **PROD-01**: Display 10 products across three tiers (Production, Active, Archive) as per PRD.
- [ ] **PROD-02**: Integrate interactive BRD/ERD artifact overlays within case studies.
- [ ] **PROD-03**: Automated "Impact Counter" for hours saved/projects shipped.
- [ ] **PROD-04**: 3D-tilt product cards with light-source tracking.

### 4. Direct Interaction & Intelligence (DIR)
- [ ] **DIR-01**: Functional Terminal UI for personality commands and technical shortcuts.
- [ ] **DIR-02**: AI Assistant with tuned system prompt matching Anvith's builder philosophy.
- [ ] **DIR-03**: Hybrid Nav: 2D "Command Center" for accessibility + 3D spatial markers.

### 5. Accessibility & Optimization (OPT)
- [ ] **OPT-01**: Mirror all 3D context in semantic HTML for screen readers.
- [ ] **OPT-02**: Respect `prefers-reduced-motion` with instant state-change fallbacks.
- [ ] **OPT-03**: Thumb-friendly mobile navigation with simplified spatial elements.
- [ ] **OPT-04**: Ensure ₹0 infrastructure overhead (Vercel free-tier compliant).

## v2 Requirements
