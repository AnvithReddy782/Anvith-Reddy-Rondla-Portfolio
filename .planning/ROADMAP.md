# Roadmap: Anvith Portfolio (Spatial Blueprint)

## Overview
A 12-phase journey from a polished v1 baseline to a next-level spatial experience. We move from establishing the 3D environment to implementing the signature "Blueprint Reveal" interaction, culminating in a high-performance, cinematic portfolio that proves Anvith's builder trajectory.

## Phases

- [ ] **Phase 1: Environment & Orchestration** - Setup R3F, GSAP, and dependency foundation.
- [ ] **Phase 2: Identity Shift & Token Migration** - Transition from "Axiom" branding to "Anvith" identity.
- [ ] **Phase 3: The Spatial Backdrop** - Implementation of the reactive 3D Grid engine.
- [ ] **Phase 4: Blueprint System Foundation** - Creating the "Wireframe-to-UI" shader/effect layer.
- [ ] **Phase 5: Hybrid Command Center** - Refactoring navigation into a 2D/3D hybrid interface.
- [ ] **Phase 6: Primary Product Narrative** - Implementing the "Production" tier spatial case studies.
- [ ] **Phase 7: The Documentary Layer** - Interactive BRD/ERD artifact overlays.
- [ ] **Phase 8: Active & Utility Grids** - 3D Tilt card implementation for Active/Archive tiers.
- [ ] **Phase 9: Agentic Interaction** - AI Assistant evolution and system specs UI.
- [ ] **Phase 10: Performance, A11y & Optimization** - On-demand rendering and screen reader mirror.
- [ ] **Phase 11: Cinematic Orchestration** - FLIP transitions and final animation polish.
- [ ] **Phase 12: Production Readiness** - Documentation cleanup and final ₹0 deployment.

## Phase Details

### Phase 1: Environment & Orchestration
**Goal**: Establish the technical runtime for 3D and high-precision animation.
**Depends on**: Nothing
**Requirements**: [VIS-04]
**Success Criteria**:
  1. `three`, `@react-three/fiber`, and `gsap` are installed and configured.
  2. A basic R3F Canvas renders without errors in the development build.
**Plans**: 1 plan

### Phase 2: Identity Shift & Token Migration
**Goal**: Purge "Axiom" references and establish the new personal branding tokens.
**Depends on**: Phase 1
**Requirements**: [VIS-02]
**Success Criteria**:
  1. No "Axiom" strings or brand colors remain in CSS or components.
  2. "Anvith Reddy Rondla" identity is established in global layout and metadata.
**Plans**: 2 plans

### Phase 3: The Spatial Backdrop
**Goal**: Build the reactive 3D Grid that drives the site's atmosphere.
**Depends on**: Phase 2
**Requirements**: [VIS-01, VIS-03]
**Success Criteria**:
  1. 3D Dot Grid follows cursor with smooth damping.
  2. Grid density/depth shifts based on scroll velocity.
**Plans**: 2 plans

### Phase 4: Blueprint System Foundation
**Goal**: Implement the core "Reveal" shaders that transition planning to production.
**Depends on**: Phase 3
**Requirements**: [INT-01, INT-02]
**Success Criteria**:
  1. Components reveal with blueprint/wireframe effects during scroll entry.
  2. Visual transition from "Documentation Layer" to "UI Layer" is functional.
**Plans**: 3 plans

### Phase 5: Hybrid Command Center
**Goal**: unify 2D controls with the 3D spatial markers.
**Depends on**: Phase 4
**Requirements**: [DIR-01, DIR-03]
**Success Criteria**:
  1. Terminal UI is integrated and functional.
  2. Navigation works seamlessly across 2D/3D spatial boundaries.
**Plans**: 2 plans

### Phase 6: Primary Product Narrative
**Goal**: Deliver immersive evidence for the top-tier "Production" products.
**Depends on**: Phase 5
**Requirements**: [PROD-03]
**Success Criteria**:
  1. Annapurna and DPMUMS have unique spatial narrative sequences.
  2. Impact counters roll up as users enter their sections.
**Plans**: TBD
